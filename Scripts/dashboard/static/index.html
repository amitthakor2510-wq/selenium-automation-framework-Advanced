Site presets

Run only

Restrict the next run to specific classes. Blank = no restriction. Comma-separated, package.* allowed.

Groups

Disables every test carrying a TestNG group, e.g. perf. A test with several groups is disabled if any one of them is off.

Tests

test-config.properties — switches individual test classes on/off, grouped by suite. A test switched off is skipped everywhere, not reported as skipped.
